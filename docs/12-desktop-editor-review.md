# Desktop editor review

**Reviewed:** 13 October 2026. **Target:** Windows Debug simulator, 800 × 480 logical display. **Result:** Phase 2 desktop acceptance passed; Pi touch and audio acceptance remain separate.

The checks below use the actual shared LVGL views. `ctest --preset windows --output-on-failure` passes all three tests. Native rendering is checked before any user input; pointer and keypad workflows use LVGL input devices on an in-memory display. Screenshots come from LVGL, rather than an HTML recreation.

| Check | Result and evidence |
| --- | --- |
| First frame | Native Win32 buffer is 800 × 480, has a completed flush and substantial background/module pixels. `build/windows-render-check.bmp` and `.txt` record the result. |
| Sparse/dense layouts | Five-module series graph and fifteen-module grid reviewed; header/footer controls leave the canvas clear. A sixteenth module is placed outside a full viewport and revealed automatically. |
| Movement/panning | Module taps open parameters; dragging snaps and clamps at canvas bounds. Empty-space panning leaves graph positions and dirty state unchanged. Home restores the view. Cable hit testing and dragging remain correct after panning. |
| Module actions | Long press and parameter-page Actions open the same menu. Duplicate preserves values/software bypass with a new ID, without copied cables or assignments. Rejection leaves the graph unchanged. Delete cleans related cables. |
| Cables/routing | Output-to-input preview highlights valid targets. Tap selects; Deselect leaves the graph unchanged; Delete removes only the selected edge. Cycles, duplicate edges, wrong directions and non-audio ports are refused. Domain checks cover all mono/stereo combinations and explicit channel symbols. |
| Parameter types/pages | Sliders, logarithmic ranges, integer values, switches and mode selectors exercised. Clouds' six demo parameters span two pages; editing page two preserves values on page one. Software bypass is labelled. |
| Catalogue status | Available demo entries can be added. Untested and unavailable fixture entries have disabled Add buttons and readable reasons when their rows are tapped. Catalogue pages fit four entries each. |
| Missing module | Settings fixture retains five instances, saved parameter values and four logical cables. The missing square remains visible; its orange cables are inactive, parameters/bypass/duplication are disabled, and moving/deleting it remains possible. |
| New/rename/save/load | Blank names are refused. Actual keyboard taps exercise letters, Backspace, OK and Cancel. Unsaved replacement can be cancelled without losing the draft. Rejected creation preserves the current graph. New patches have IN/OUT and a direct logical cable. Rename keeps the graph. Engine-acknowledged session save clears dirty state; restore survives creation of another patch. |
| Physical keyboard | Tab traverses buttons, Enter activates Add, and printable keys enter a name. Physical Enter opens the replacement guard. Screen rebuilding waits for both pointer and keypad release, preventing a held Enter from activating a new screen's Back button. |
| Long names/edges | Long patch names truncate on one header line; long square names truncate inside the square. Navigation, labels and ports remain visible. Dragging toward the top/left edge clamps and snaps without opening parameters. |
| Error/reconnection | Delayed requests, rejected edits/save/creation, unavailable capabilities, disconnect cancellation and reconnect exercised. Persistent storage, plugin-state capture and audio processing are explicitly unsupported in this simulator. |
| Module-specific layouts | Clouds Texture and Mix / hold pages and Delay Character mode buttons reviewed at 800 × 480. Density, integer pitch, mix, freeze, logarithmic delay time, feedback and modes exercised through real pointer gestures. Rejected mode edits retain the acknowledged value. All / Custom switches preserve values; an extended Clouds schema falls back to the generic editor and its extra parameter remains editable. Captures: `ui-clouds-texture.png`, `ui-clouds-mix-hold.png`, `ui-delay-character.png` (the first two removed on 17 October 2026 with those pages). |
| Parallel starter | Patches → Parallel demo guards unsaved edits, supports cancellation/rejection, then displays a five-edge stereo split/merge graph. Domain checks expand all five logical cables into ten physical channel connections and reject feedback. Pointer checks remove/reconnect one split branch without removing the other. `ui-parallel-patch.png` records the layout. Audio mixing is not simulated. |
| Global readouts | Persistent bottom-right footer displays BPM and CPU, including on parameter/keyboard pages. Rendered parallel, Delay and selected-cable views reviewed: badge and cable actions fit without overlap. Existing cable select/deselect/delete and keyboard workflows pass after adjusting action positions. Values are 120 BPM / 12% CPU SIM fixtures; CPU is unavailable outside Ready. Optional telemetry updates text/color only when changed and does not rebuild gesture targets. Real clock synchronization and CPU measurement remain unverified. |

Review captures are under `docs/images/`; test BMPs are under the ignored `build/screenshots/` directory. See [UI development](11-windows-ui-foundation.md) for startup evidence and [domain/engine contracts](13-domain-and-engine-contracts.md) for routing and lifecycle semantics.

This review establishes desktop editor behavior. It does not verify LV2 discovery, actual Ingen port names, summing levels, audio performance, Pi deployment, display DPI at standing distance, or finger usability. Phase 3 must measure merge behavior before compensation or mixing policy becomes an audio claim; Phase 4 must repeat touch interaction checks on the instrument.
